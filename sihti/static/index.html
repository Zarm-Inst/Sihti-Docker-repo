            Estolausekkeet

            Säännöllinen lauseke, jota verrataan koko nimeen. Esim. (^|\.)track

                Ylävirran DNS-palvelimet

                Yksi per rivi. Portti voi olla mukana, esim. 192.168.1.1:5353.

                Estetyn nimen vastaus
                Päällekkäiset estolistat

                Nopeuttaa listojen päivitystä. Ohitetut listat tarkistetaan viikoittain ja otetaan automaattisesti takaisin käyttöön, jos niihin tulee nimiä, joita muilla listoilla ei ole. Yksittäisen listan voi pitää aina käytössä Estolistat-sivulta.

                Suojaus

                Muuten Firefox ja Apple-laitteet voivat ohittaa tämän verkon suodatuksen. Apple-laitteet ilmoittavat, että verkko on kytkenyt Private Relayn pois. Esto on voimassa myös silloin, kun suodatus on tauolla tai pois päältä, jotta laitteet eivät siirry ohittamaan Sihtiä tauon aikana. Ohitusnimen voi sallia omalla sallinnalla.

                Estää myös nimet, jotka osoittavat (CNAME) estettyyn nimeen, esim. sivuston oman aliverkkotunnuksen taakse piilotetun seurannan.

                Sihti ei toimi avoimena DNS-palvelimena, vaikka portti 53 aukeaisi vahingossa internetiin. Lähiverkon IPv4- ja IPv6-osoitteet sallitaan automaattisesti.

                Paikalliset nimet

                Lähiverkon laitteiden nimet (esim. nas.lan tai pelkkä nas) ja lähiverkon osoitteiden käänteishaut kysytään reitittimeltä eikä internetistä. Jätä osoite tyhjäksi, jos et käytä laitteiden nimiä.

                Suojattu yhteys (HTTPS)

                Jotta selain ei varoittaisi yhteydestä, asenna Sihdin varmentaja kerran jokaiselle laitteelle, jolla käytät tätä sivua. Sen jälkeen varmenteen automaattiset uusimiset eivät näy mitenkään. Tarkista asennuksessa, että varmentajan sormenjälki on sama kuin yllä.

                Lataa varmentaja

                Windows

                Avaa ladattu tiedosto → Asenna varmenne → Paikallinen kone → Sijoita kaikki varmenteet seuraavaan säilöön → Luotetut päävarmenteiden myöntäjät. Käynnistä selain uudelleen.

                macOS

                Avaa tiedosto, jolloin se lisätään Avainnippuun. Etsi Avainnipussa Sihti paikallinen varmentaja, avaa se ja valitse kohdassa Luottamus → Luota aina.

                iPhone ja iPad

                Avaa tämä sivu Safarilla ja lataa tiedosto → Asetukset → Profiili ladattu → Asenna. Ota sitten käyttöön kohdassa Asetukset → Yleiset → Tietoja → Varmenteiden luottamusasetukset.

                Android

                Lataa tiedosto → Asetukset → Tietoturva → Lisää tietoturva-asetuksia → Salaus ja kirjautumistiedot → Asenna varmenne → CA-varmenne. Valikon nimet vaihtelevat valmistajittain.

                Linux ja Firefox

                Linux: sudo cp sihti-varmentaja.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates. Firefox käyttää omaa säilöään: Asetukset → Tietosuoja ja turvallisuus → Näytä varmenteet → Myöntäjät → Tuo ja valitse Luota tähän varmentajaan sivustojen tunnistamisessa.

                Käyttöliittymän salasana

                Salasana on satunnainen ja vaihtuu jokaisella käynnistyksellä. Sitä ei voi vaihtaa täältä. Voimassa oleva salasana on Sihdin lokin viimeisellä rivillä, joka alkaa Sihti random password:

                Docker
                docker logs sihti 2>/dev/null | grep "random password" | tail -n1
                Ilman Dockeria
                sudo journalctl -u sihti | grep "random password" | tail -n1
